Rules:

- Each comment is copied **verbatim** (original language) from the supervisor's form, e-mail, meeting notes or GitHub comment. The team does not summarize a comment as approval.
- **Decision:** `Accepted`, `Partly accepted` or `Not accepted`. A partial or non-acceptance needs a reason that was discussed with the supervisor.
- **Change:** link to the pull request or commit that makes the change, or `–` if no change is needed.
- DOA-14 is closed when every row has a decision and, where a change was made, a link.
